The desktop app ships as IPTV Player NEW: its own application identity, window
title, installer metadata and Windows x64 NSIS packaging. App data lives under
its own `~/.iptv-player-new` profile and never imports another IPTVnator
installation's data, and in-app updates stay off until a release feed is
announced.
