# android-player

Capacitor 8 shell for the Android / Android TV runtime.

Phase 0 only: prove that the existing web app (`apps/web`, PWA build) runs
inside a debug APK on an emulator/device. No Media3 plugin, D-pad focus, TV
shell or native persistence yet — those are phases 1–3
(`docs/superpowers/specs/2026-10-22-android-tv-design.md`, sections 3, 4 and 6).

## Structure

- `capacitor.config.ts` — Capacitor config. `webDir` is resolved relative to
  the directory the `cap` CLI is invoked from (`process.cwd()`), so all `cap`
  targets in `project.json` run with `cwd: apps/android-player` and
  `webDir: '../../dist/apps/web'` resolves to the workspace PWA output.
- `android/` — native Gradle project generated by `cap add android`
  (Capacitor 8 template: `minSdk 24`, `compileSdk 36`, `targetSdk 36`,
  Gradle 8.14.3, AGP 8.13, Java 21).

## Targets

- `pnpm nx build android-player` — PWA build → `cap sync android` →
  `gradlew assembleDebug` → APK at
  `android/app/build/outputs/apk/debug/app-debug.apk`.
- `pnpm nx sync android-player` — `cap sync android`.
- `pnpm nx assemble-debug android-player` — Gradle debug APK only.
- `pnpm nx open android-player` — open the project in Android Studio.
- `pnpm nx lint android-player`.

## Build environment

`android/gradle.properties` pins `org.gradle.java.home` to the local
Temurin 21 install. `local.properties` (SDK location) and all Gradle build
outputs are git-ignored at the repository root `.gitignore`.

## Decisions (phase 0)

- **PWA build, not `production`**: the sync source is
  `nx build web --configuration=pwa` (`baseHref: "/"`). The `production`
  configuration uses `baseHref: "./"` and relative asset URLs that the
  Capacitor WebView cannot serve.
- **Cleartext HTTP is NOT enabled globally**
  (`android:usesCleartextTraffic` stays unset, so cleartext is blocked by
  default from targetSdk 28). IPTV playlists frequently use plain HTTP; when
  provider streaming lands (phase 1+), allow it through
  `android/app/src/main/res/xml/network_security_config.xml` with an explicit
  domain allow-list instead of a global toggle. Not implemented in phase 0.
- **Service worker**: in the Capacitor WebView the origin is `https://localhost`,
  so `shouldEnableServiceWorker()` (`apps/web/src/app/services/runtime-config.ts`)
  would register the SW and serve stale chunks inside the APK. Must be handled
  in the Android runtime detection (phase 1), per the design spec section 4.2.
- **Application ID**: `com.iptvplayernew.desktop`, app name `IPTV Player NEW`
  (design spec, open decisions: single application ID while only the direct
  APK channel exists).
